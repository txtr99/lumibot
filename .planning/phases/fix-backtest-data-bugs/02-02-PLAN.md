### Task 1: Fix Equity Curve Calculation (Bug #2)
**Type:** modify
**Files:** `custom_portfolio/multi_strategy_executor_enhanced.py`
**Action:**
Update lines 1107-1113 to use `get_data_at_time()`:

Before:
```python
market_data = self.shared_data.get_cached_data(
    strategy_state.symbol, self.max_lookback, self.timestep
)
if market_data is not None:
    df = market_data.df if hasattr(market_data, "df") else market_data

        market_data.df if hasattr(market_data, "df") else market_data
    )
    if len(df) > 0:
        current_price = df["close"].iloc[-1]
```

**Verify:**

### Task 2: Fix Order Execution Fallback (Bug #4)
**Type:** modify
**Files:** `custom_portfolio/multi_strategy_executor_enhanced.py`
**Action:**
Update lines 1544-1548 fallback logic:

Before:
```python
if fill_override is not None:
    fill_price = float(fill_override)
    bar_time = df.index[-1] if len(df.index) > 0 else current_time
if fill_price is None:
    # Fallback: use last bar in the frame
    fill_price = float(df["close"].iloc[-1])
    bar_time = df.index[-1] if len(df.index) > 0 else current_time
```

The issue: `df` here is the full unfiltered data. Need to filter first.

After:
```python
# Ensure df is filtered to current_time to prevent lookahead
if hasattr(df, 'index') and len(df) > 0:
    ct = pd.Timestamp(current_time)
    if df.index.tz is not None and ct.tzinfo is None:
        ct = ct.tz_localize(df.index.tz)
    elif df.index.tz is None and ct.tzinfo is not None:
        ct = ct.tz_convert(None)
    df_filtered = df[df.index <= ct]
    if len(df_filtered) > 0:
        df = df_filtered

if fill_override is not None:
    fill_price = float(fill_override)
    bar_time = df.index[-1] if len(df.index) > 0 else current_time
if fill_price is None:
    # Fallback: use last bar in the filtered frame
    fill_price = float(df["close"].iloc[-1])
    bar_time = df.index[-1] if len(df.index) > 0 else current_time
```

**Verify:**
- Fallback now uses filtered data
- bar_time comes from filtered data (fixes Bug #5)
