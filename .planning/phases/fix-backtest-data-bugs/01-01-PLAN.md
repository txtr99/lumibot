# Phase 01-01: Create Diagnostic Test Script

## Objective
Create a minimal diagnostic script that captures and logs lookahead behavior to confirm Bugs #1 and #2.

## Context
@custom_portfolio/tools/shared_data_manager.py
@custom_portfolio/multi_strategy_executor_enhanced.py

## Tasks

### Task 1: Create Diagnostic Script
**Type:** create
**Files:** `custom_portfolio/tools/tmp_lookahead_diagnostic.py`
**Action:**
Create a script that:
1. Simulates what the backtest does: gets cached data and reads `df["close"].iloc[-1]`
2. Logs for each simulated iteration:
   - `current_time`: the simulated backtest time
   - `df.index[-1]`: the last index in the returned dataframe
   - `df["close"].iloc[-1]`: the price being used
3. Clearly shows if `df.index[-1]` is always the same (proving lookahead)

**Verify:**
- Script runs without error
- Output shows that `df.index[-1]` is constant across iterations (confirming Bug #1)

### Task 2: Run and Capture Output
**Type:** execute
**Command:** `source venv/bin/activate && python custom_portfolio/tools/tmp_lookahead_diagnostic.py`
**Action:** Run the diagnostic and capture output to confirm the bug
**Verify:**
- Output clearly shows the last bar is always the same regardless of simulated current_time
- This confirms the cached data is NOT being filtered

## Verification
- [ ] Script created and executable

- [ ] Can clearly explain how the fix should work based on evidence
