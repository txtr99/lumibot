KEY INSIGHTS
================================================================================

What's Broken Today:
  1. No state recovery mechanism → all state lost on restart
  2. No orphaned order cleanup → stale orders persist
  3. Bracket flag reset on restart → resubmits brackets
  4. Flatten failure → potential infinite loop
  5. No cold start safety → auto-flattens without review

Why It Matters:
  - Financial Impact: Could liquidate profitable positions
  - Operational: Exchange sees erratic behavior, duplicate orders
  - Compliance: Difficult to audit and explain
  - Risk: High probability in live trading environment

How It Could Happen:
  - Bot crash at any time (network, process kill, etc.)
  - State file gets corrupted (partial write, power loss)
  - Config changes between runs (strategies added/removed)
  - Orders carry over from previous session
  - Exchange API returns stale data

Root Cause:
  - State entirely in-memory (no persistence)
  - Sync check assumes exchange is correct (no fallback)
  - No recovery logic for restart scenarios
  - No archaeology for old orders
  - No atomic operations for state changes
