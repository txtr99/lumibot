# Strategy Quant X (SQX) Function Reference

Guide for converting SQX EasyLanguage exports to Python. SQX uses custom `SQ_` prefixed functions with non-obvious implementations.

## Detection

**SQX Export Indicators**:
- Header: `Generated by StrategyQuant X Build XXX`
- Functions contain `SQ_` (prefix or infix, e.g., `f_SQ_MACD`)

File naming: `f_SQ_<FunctionName>.elf`

## MANDATORY Lookup Rule

**NEVER GUESS** what an SQ_ function does. Always read the `.elf` file because:

1. **Hidden switch parameters**: `SQ_MACD(..., Line)` where Line=0 returns main, Line=1 returns signal
2. **Non-standard MA types**: `SQ_IndicatorCrossesBelowMA(..., MAType)` where 1=SMA, 2=EMA, 3=WMA, 4=Hull
3. **Nested functions**: `SQ_QQE` internally calls `SQ_EMA` - must understand both
4. **Custom implementations**: May differ from pandas-ta equivalents

## Common Patterns

### Multi-Output Indicators (Line Parameter)

Many SQX indicators return different values based on a `Line` parameter:

| Function | Line=0 | Line=1 | Line=2 |
|----------|--------|--------|--------|
| `SQ_MACD` | MACD Main | MACD Signal | - |
| `SQ_Stochastic` | %K | %D | - |
| `SQ_BollingerBands` | Lower | Middle | Upper |
| `SQ_Aroon` | AroonUp | AroonDown | - |

### MA Type Parameters

Cross/comparison functions often have MAType:

| MAType | Moving Average |
|--------|----------------|
| 1 | Simple (SMA) |
| 2 | Exponential (EMA) |
| 3 | Weighted (WMA) |
| 4 | Hull (HMA) |

### Complex Indicators Not in pandas-ta

These require custom Python implementations based on .elf source:

- `SQ_QQE` - Quantitative Qualitative Estimation (uses internal EMA + RSI)
- `SQ_EfficiencyRatio` - Kaufman Efficiency Ratio variant
- `SQ_LaguerreRSI` - Laguerre-smoothed RSI
- `SQ_DVO` - DV Oscillator
- `SQ_DeMarker` - DeMarker indicator

## Lookup Workflow

```
1. Identify: Find all SQ_ functions in entry logic
2. Read: Load each f_SQ_<name>.elf file
3. Document: Note all parameters and their meanings
4. Check nesting: If .elf calls other SQ_ functions, look those up too
5. Implement: Convert to Python with full understanding
6. Verify: Ensure parameter values match original intent
```

## Example Conversion

**EasyLanguage (SQX)**:
```
SQ_IndicatorCrossesBelowMA(SQ_MACD(MedianPrice, 16, 37, 10, 0)[1], 49, 3)[1]
```

**After lookup**:
- `SQ_MACD(..., 0)` -> Returns MACD main line (from switch case 0)
- `SQ_IndicatorCrossesBelowMA(..., 3)` -> Uses WMA (MAType=3)
- `[1]` -> 1 bar ago

**Python implementation**:
```python
def populate_indicators(df, params):
    median_price = (df["high"] + df["low"]) / 2

    # SQ_MACD with Line=0 (main line only)
    macd_main = ta.macd(median_price, fast=16, slow=37, signal=10)['MACD']

    # 49-period WMA of MACD (MAType=3 = Weighted MA)
    macd_wma = ta.wma(macd_main, length=49)

    return {
        "macd_prev": macd_main.iloc[-2],
        "macd_wma_prev": macd_wma.iloc[-2],
        "macd_2ago": macd_main.iloc[-3],
        "macd_wma_2ago": macd_wma.iloc[-3],
    }

def go_long(state, df):
    ind = populate_indicators(df, state.params)

    # Crosses below: was above, now below (1 bar ago)
    crosses_below = (
        ind["macd_2ago"] > ind["macd_wma_2ago"] and
        ind["macd_prev"] < ind["macd_wma_prev"]
    )
    return crosses_below
```

## Common SQX Function Categories

### Price/OHLC Functions
- `SQ_TypicalPrice` - (H+L+C)/3
- `SQ_MedianPrice` - (H+L)/2
- `SQ_WeightedClose` - (H+L+C+C)/4

### Trend Indicators
- `SQ_ADX` - Average Directional Index
- `SQ_Aroon` - Aroon indicator (Line parameter)
- `SQ_ParabolicSAR` - Parabolic SAR
- `SQ_SuperTrend` - SuperTrend indicator

### Momentum/Oscillators
- `SQ_RSI` - Relative Strength Index
- `SQ_MACD` - MACD (Line parameter for main/signal)
- `SQ_Stochastic` - Stochastic (Line parameter for %K/%D)
- `SQ_CCI` - Commodity Channel Index
- `SQ_QQE` - Quantitative Qualitative Estimation

### Volatility
- `SQ_ATR` - Average True Range
- `SQ_ATR_R` - ATR variant (check .elf for differences)
- `SQ_BollingerBands` - Bollinger Bands (Line parameter)
- `SQ_BBWidthRatio` - Bollinger Band Width Ratio

### Moving Averages
- `SQ_SMA` - Simple Moving Average
- `SQ_EMA` - Exponential Moving Average
- `SQ_WMA` - Weighted Moving Average
- `SQ_DEMA` - Double EMA
- `SQ_TEMA` - Triple EMA
- `SQ_HullMA` - Hull Moving Average

### Cross/Comparison Functions
- `SQ_IndicatorCrossesAboveMA` - Indicator crosses above its MA
- `SQ_IndicatorCrossesBelowMA` - Indicator crosses below its MA
- `SQ_PriceCrossesAboveIndicator` - Price crosses above indicator
- `SQ_PriceCrossesBelowIndicator` - Price crosses below indicator

### Candlestick Patterns
- `SQ_BullishEngulfing`
- `SQ_BearishEngulfing`
- `SQ_Hammer`
- `SQ_Doji`
- `SQ_DarkCloud`

### Utility Functions
- `SQ_ConvertToPips` - Convert price to pips
- `SQ_CorrectMinMaxSLPT` - Correct SL/PT within min/max bounds
- `SQ_BarsSinceEntry` - Bars since position entry
- `SQ_Highest` - Highest value over N bars
- `SQ_Lowest` - Lowest value over N bars
